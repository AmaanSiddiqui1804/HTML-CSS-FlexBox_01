HTML (Hypertext Markup Language)
HTML is the standard markup language used to create and structure content on the web. It defines the structure of web pages by using elements such as headings, paragraphs, links, images, and forms. HTML provides the skeleton of a webpage, organizing content with tags and attributes to allow browsers to display information to users effectively.

CSS (Cascading Style Sheets)
CSS is a stylesheet language used to control the presentation and layout of HTML elements. It allows developers to apply styling rules like colors, fonts, spacing, and positioning. With CSS, you can make web pages visually appealing and responsive, adapting the design to different screen sizes and devices through media queries and various layout techniques.

Flexbox (Flexible Box Layout)
Flexbox is a powerful CSS layout model that enables efficient alignment and distribution of space among items in a container. It allows for flexible and responsive designs with fewer complications than traditional layout techniques. Flexbox makes it easy to control the alignment, order, and spacing of elements, making it ideal for building modern, dynamic web layouts that adapt seamlessly to different screen sizes.
